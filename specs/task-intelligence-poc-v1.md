# Task Intelligence POC v1

Status: executable owner-operated POC contract for MVP-C1.

The supported pilot route is a reviewed source patch that registers the real
Gradle input and output and opts the task into native cacheability. Historical
outputs never qualify a task. The diagnostic Java Agent and experimental Linux
helper retain their measured `UNAVAILABLE` results and abort pending data;
neither is silently promoted to access or hermeticity evidence.

`internal/taskintelligence` owns the explicit qualification states, complete
coverage decision, reviewed-contract checks, quarantine gates, Test exclusion,
and exact task/key/PUT/outcome publication decision. Every incomplete trace,
dropped event, diagnostic fault, inactive task, discrepancy, or unattributed
PUT keeps the baseline authoritative and aborts the whole pending attempt.

The public synthetic pilot moves through `UNKNOWN → OBSERVING →
CONTRACT_QUALIFIED → QUARANTINE_VALIDATED → ACTIVE` only after the exact
`CUSTOM_TASK_CONTRACT_JAVA_V1` patch passes its real build and CI checks. Four
paired alternating runs compare the immutable pre-patch revision with the
accepted merge revision. The candidate must restore the task from native cache,
produce byte-identical output, have a positive lower 95% exhaustive-bootstrap
bound, and preserve p95/p99 and OOM guardrails.

Run the focused implementation contract with:

```bash
./dev/check-task-intelligence-poc
```

The checked-in evidence is owner-operated POC evidence. It does not run the
deferred eight-hour soak or authorize production promotion.
