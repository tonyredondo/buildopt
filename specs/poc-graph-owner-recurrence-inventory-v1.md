# Graph Owner Recurrence Inventory v1

Status: `GORI-001` complete; `GORI-002` is current.

This source-only successor inventories every exact `owners + change family`
group in the same three SHA-bound GABD histories. It is not anchored to the
fixture owner. A group is recurrent at five commits in the fixed 64-row window.
Repository and task names cannot affect grouping or selection.

The route may identify candidates for a separately frozen correctness
experiment. It may not run Gradle, patch public source, execute candidates,
collect timing or infer value from recurrence alone.
