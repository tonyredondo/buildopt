# Graph-Aware Breadth Discovery v1

Status: `GABD-001` complete; `GABD-002` is current.

This experiment searches for a second naturally recurrent public family before
spending another Gradle build. It runs the graph-aware source-history auditor
against the retained, reviewed graphs for Groovy, OpenTelemetry and Micronaut.
Kafka and Spring are fixed controls from GAH v1.

Every row is bound to its exact public target, manifest, graph, owner and
change family. The scan reads a maximum of 64 first-parent commits and requires
five exact owner/family matches. It may clone public Git history without blobs,
but must not run Gradle, patch public source, execute a candidate, collect
timing, use repository/task names as rules, or consume predecessor summaries as
classification evidence.

If no additional family reaches five matches, the route stops without builds
and the next successor must change the opportunity hypothesis. If at least one
does, a separate contract must freeze fresh candidate correctness before any
Gradle execution.
