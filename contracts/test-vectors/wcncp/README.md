# Wrapper-coordinated native correction vectors

These language-neutral vectors freeze one schema-valid and one deliberately
invalid document for each immutable WCNCP control-state record. They contain
synthetic identities and no public-repository observation or timing evidence.

The valid set proves the closed shape for observation, opportunity, proposal,
controlled validation, and owner decision. The invalid set proves that hosted
CI cannot supply controlled observation or materiality evidence, and rejects
automatic source authority, hosted-CI value qualification, and an owner
decision that claims source application.

Run:

```bash
./dev/check-wrapper-coordinated-native-corrections-plan
```

`WCNCP-000` owns these vectors. Passing them authorizes only `WCNCP-001` typed
state implementation; they do not expose a route, execute Gradle, or authorize
a proposal.
