# Sticky wrapper learning fixture

This deterministic fixture is implemented by the focused Go tests and the
committed lifecycle evidence. It uses generic action and binding identifiers;
it does not recognize a repository, task name or checkout path.

The fixture injects only the four private seams frozen by the POC plan: clock,
detector, paired-trial runner and decision publisher. All process execution is
still adapted through the launcher supervisor. It proves a profitable active
path, a regressed active path that suspends, retirement, and native fallback
for every missing-authority or invalid-decision case.

Run it with:

```bash
./dev/check-sticky-wrapper-learning-lifecycle
```
