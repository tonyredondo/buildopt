# Native volatility quarantine result

This bounded POC proves a generic producer-atomic response to native output
volatility. Two independent observations are compared by complete path set,
binding, producer attribution and SHA-256. Any differing output quarantines its
whole Gradle producer; all outputs from that producer are rebuilt locally, and
only outputs from stable producers remain transportable.

The executable four-output fixture changes one file from a two-output
producer. The result quarantines both producer outputs, transports the two
stable outputs and accepts the candidate only after the quarantined pair is
rebuilt. Modified transported bytes, incomplete path sets and producer
ambiguity are rejected.

The frozen public Spring JMS result remains visible: its positive 11.43%, 8/8
calibration compared 8,385 class files across independent roots and found 14
differences. Thirteen paths belong to the main AspectJ compiler output and one
to the main Java compiler output, mapping to two generic Gradle producer tasks.
This is a repairable producer-quarantine shape, not a completed Spring replay.
The compact historical evidence does not contain the complete producer-bound
inventory for that exact revision, so this block does not authorize a filtered
pack, add a performance claim or broaden the Kafka cross-commit result.

Recompute the contract and evidence checks with:

```bash
./dev/check-native-volatility-quarantine
```
