# Ordinary-build lifetime breadth V3 result

This bundle is the terminal evidence for `POC-LIFETIME-BREADTH-V3-001`.
One exact installed BuildOpt executable ran the frozen Spring Framework,
OpenTelemetry Java Instrumentation, Apache Kafka, Micronaut Core and Apache
Groovy windows. The protocol used only requested ordinary builds, retained the
unchanged robust qualification gate and stopped early when five-match lifetime
economics could not justify further learning.

## Result

| Repository | Requested qualification builds | Historical matches | Robust target result | Descendant selection | Signed lifetime net |
| --- | ---: | ---: | --- | ---: | ---: |
| Spring Framework | 1 | 4 | Stopped before pairs | 0 / 0 | **-10.113 s** |
| OpenTelemetry | 1 | 1 | Stopped before pairs | 0 / 0 | **-9.961 s** |
| Apache Kafka | 17 | 12 | **+6.673 s / 21.43%, 8/8** | **1 / 6** | **+82.527 s** |
| Micronaut Core | 1 | 1 | Stopped before pairs | 0 / 0 | **-9.149 s** |
| Apache Groovy | 1 | 1 | Stopped before pairs | 0 / 0 | **-2.760 s** |

Kafka's one selected replay saves 135.127 seconds. Its five native-retained
descendants add 42.040 seconds of directly measured wrapper work, and
qualification plus publication costs 10.560 seconds. The resulting attributable
Kafka net is +82.527 seconds. All six descendants are structurally eligible,
so selection coverage is 1/6 rather than 1/1.

The aggregate uses 21 requested builds, zero measurement-only builds, verifies
27 exact-output observations and records zero product failures. Its signed net
is +50.544 seconds, but that total is descriptive and is neither a repository
average nor a substitute for breadth. Only 1/5 repository families is net
positive and 1/6 eligible descendants selects, below the frozen 3/5 and 50%
thresholds. The terminal decision is therefore
`FUNCTIONAL_COVERAGE_NOT_PROVEN`.

The four early-retained subjects avoided 64 additional qualification builds.
This proves that ordinary-build lifetime prequalification prevents expensive
learning when compatible history is too short. It does not prove generic
cross-commit acceleration.
