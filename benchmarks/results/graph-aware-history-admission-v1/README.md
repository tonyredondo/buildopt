# Graph-Aware History Admission v1 evidence

`summary.json` is a compact checked index of two fresh source-only audits. The
auditor read the retained exact discovery snapshots and fresh public
first-parent Git histories. It did not read predecessor opportunity reports,
run Gradle, patch public source, execute candidates or collect timing.

Kafka reproduces `ADMIT` at 12/5 compatible commits. Spring reproduces
`REJECT` at 1/5. The exact compatible commit identities are retained so the
result cannot be replaced by unchecked aggregate fields.
